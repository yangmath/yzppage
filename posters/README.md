# 论文海报上传目录

将文件上传到本目录（`posters/`），文件名使用下面对照表中对应的名称。上传至 `main` 分支并等待网站部署完成后，Research 栏目的 [Poster] 链接即可使用，无需修改网页。

- 文件名区分大小写，请保留全部小写、连字符及扩展名。
- 文件名与论文列表的编号无关，排序或发表状态变化后无需改名。
- 替换已有文件时保持同名，链接即可保持不变。
- 默认存放 PNG 原图，不做压缩转换。如果使用 JPG 或 PDF，请同时把 `index.html` 中该文章 Poster 链接的扩展名改成实际扩展名。
- 文件尚未上传时，相应链接会返回 404；无需上传空白文件作为占位。
